# Legacy: the March 2025 Mamba forecaster

This directory holds the code the repository started from, moved here on
2026-10-11 without modification: `src/models/` (the Mamba model and its data
module), `train.py`, `tests/test.py`, its `pyproject.toml`, `uv.lock` and
`Makefile`, and `README.md` describing it. It depends on the `lightning`
package and mlflow, a stack the current code does not use, and it is not part
of the `timessm` package. The layout it had at the repository root is tagged
`mamba-2025`.
